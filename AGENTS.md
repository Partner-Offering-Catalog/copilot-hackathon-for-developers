# Repository agent rules

- Work only in the participant's repository created from this template; never
  create issues, projects, milestones, or pull requests in the template.
- Do not edit files under `.github/`, except an explicitly requested workflow
  under `.github/workflows/`.
- Use focused feature branches and keep changes limited to the assigned task.
- Never commit credentials, tokens, private keys, or sensitive data.
- Run the existing relevant validation before proposing a pull request.
- Ask for clarification when requirements, acceptance criteria, or deployment
  targets are incomplete.
